🔤 Character Counter
📌 About

Character Counter is a simple and user-friendly web application that counts the number of characters in a given text. It helps users track characters while typing or editing text.

✨ Features
Count total characters.
Count characters with spaces.
Count characters without spaces.
Count words.
Real-time character counting.
Simple and attractive user interface.
Responsive design.

🛠️ Technologies Used
HTML5
CSS3
JavaScript

🚀 How to Run
Clone this repository:
bash
git clone YOUR_REPOSITORY_URL

Open the project folder.
Open index.html in your browser.
Type or paste your text into the text area.
View the character and word counts instantly.

🎯 Purpose

This project is created to improve frontend development skills and practice JavaScript DOM manipulation, event handling, and real-time text processing.
